# Комплексний аналіз успішності та моделювання даних освітнього процесу в Power BI

## Опис проєкту
Цей проєкт створений для побудови аналітичної звітності для відстеження успішності учнів, оцінки ефективності викладачів та моніторингу ключових показників освітнього процесу. Проведено повний цикл від збору "сирих" даних до створення інтерактивного дашборду.

## Технічний стек
*Інструменти:* Power BI Desktop;
*Трансформація даних (ETL):* Power Query, мова M;
*Моделювання:* Схема «Зірка» (Star Schema);
*Обчислення та аналітика:* DAX (Time Intelligence, швидкі міри).

## Архітектура та Модель даних
У проєкті реалізовано оптимальну модель даних типу "Зірка". Створено зв'язки між таблицею фактів (оцінки/успішність) та таблицями вимірів (учні, вчителі, класи, календар).

## Основний функціонал дашборду
*Динамічна навігація:* зручне перемикання між звітами за допомогою кастомного меню;
*Спливаючі підказки (Tooltips):* при наведенні на учня чи клас відображається додаткова експрес-аналітика успішності;
*Наскрізна деталізація (Drill-through):* можливість "провалитися" в картку конкретного учня для детального аналізу його оцінок у часі.
